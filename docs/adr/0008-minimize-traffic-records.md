# Minimize traffic records

The service records no browsing destinations, content, or DNS queries. It keeps masked security and connection events for seven days, aggregate monthly usage for three months, and administrative actions for twelve months. Usage leaves the node as client-side-encrypted append-only batches; the off-node store uses separate private usage and policy buckets, bucket locks, lifecycle deletion, and opaque object names.

This privacy position deliberately limits automated abuse attribution. The pilot relies on narrow port controls, aggregate limits, scan-like behavior, provider reports, and operator suspension without content inspection. A qualified legal review must reconcile any applicable identity or retention duties before external tester admission or payment.
